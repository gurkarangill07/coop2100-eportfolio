## Preview and publish

Run `python3 -m http.server 8000 --bind 127.0.0.1` from the repository root, then open `http://127.0.0.1:8000/`.

GitHub Pages serves the `main` branch at the repository root. Push changes to `main` and check the **pages build and deployment** workflow before reporting deployment complete.

Site: https://gurkarangill07.github.io/coop2100-eportfolio/

The site uses only HTML, CSS, and a small amount of JavaScript, so no build process is required.
