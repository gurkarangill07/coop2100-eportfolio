March 2026 · Student tool

YorkU Course Availability Notifier

The notifier helps York University students track course sections and get an email when a seat opens.

  • Technologies JavaScript, Node.js, Express, Playwright, and PostgreSQL.
  • My contribution Built the seat monitor, connected the API to the web interface, designed the database and sign-in flow, and built the queue for notification retries and duplicate prevention. A teammate implemented email delivery.
  • Result The tool reached approximately 500 student users and gave them a way to monitor availability without repeatedly checking the schedule.

  • Technologies Next.js, React, TypeScript, Python, OpenCV, MediaPipe, and Ollama.
  • My contribution Proposed the concept, implemented frontend features for score display, timing, and reminders, and connected the AI coach interface to backend APIs.
  • Result The team integrated webcam monitoring, a posture dashboard, and a local AI coach into one prototype.
